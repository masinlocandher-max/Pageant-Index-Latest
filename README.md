# Pageant Index Latest

Canonical clean rebuild of **Pageant Index**, the global index and operating infrastructure for pageantry.

## Core products

1. **Index** — structured records of legitimate people, organizations, pageants, editions, roles and relationships.
2. **Vote** — official organization-authorized public/fan voting.
3. **Tabulate** — secure competition scoring, computation, audit and results workflows.
4. **Credential** — document-based self-indexing, verification and NFC Tap ID credentials.
5. **Privileges** — partner benefits for Indexed individuals, with enhanced Elite privileges.

## Current build rule

This repository is **frontend-first**. No backend, production authentication, payments, database, or external service is required at this stage.

The admin console is the primary operating surface. All prototype workflows use browser-local state so the complete product can be reviewed and tested before backend integration.

See `docs/PRODUCT-SOURCE-OF-TRUTH.md` for the canonical product rules.
